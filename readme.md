# Fabric Sales Analytics Accelerator

A beginner-friendly Microsoft Fabric accelerator that automates the setup of a sales analytics solution using Fabric Lakehouse, Power BI, pipelines, and F2 capacity.

---

## Features

- Microsoft Fabric Workspace Setup
- F2 Capacity Automation
- Lakehouse Architecture
- Sample Sales Data
- PowerShell Deployment Scripts
- SQL Analytics
- Power BI Reporting
